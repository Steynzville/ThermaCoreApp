# Investor product summary

ThermaCoreApp is a web application for monitoring tenant-owned units that may deliver electrical power, useful heat, useful chilling and AWG potable water. It combines a shared portfolio, operational conditions/history, maintenance, acknowledged control integration, ordinary financial/operating Analytics, a separate premium SCADA experience and real selected-unit document exports.

The repository supports two explicit deployments of shared production code: Demo-App supplies labelled fictional demonstration data; main defaults to authenticated recorded data without fictional fallback. A working demonstration is not evidence of commissioned hardware, customer deployment or revenue.

Potential commercial offerings may combine equipment sales and software services. The code implements premium SCADA entitlement; it does not establish prices, subscription billing, margins, installed customer counts or financial forecasts. Sales displays recorded commercial data separately from operational telemetry.

Security includes backend ownership/permission checks, scoped Socket.IO, verified provider/passkey authentication and acknowledgement-based controls. External credentials, real telemetry, authenticated gateways, camera feeds and site safety remain commissioning requirements. No regulatory certification, two-person approval or immutable cryptographic ledger should be inferred. The optional OPC-UA advisory remains documented.
